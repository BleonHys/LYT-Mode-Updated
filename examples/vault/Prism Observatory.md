# Prism Observatory

Ein ruhiger Ort für **klare Gedanken**, *unerwartete Verbindungen* und die nächste gute Frage.

> [!abstract] Ein Gedanke, mehrere Perspektiven
> Wie ein Prisma Licht auffächert, kann eine Notiz verschiedene Seiten einer Idee sichtbar machen. Farbe gibt Orientierung; der Inhalt bleibt im Mittelpunkt.

## Verbindungen entdecken

Eine Idee wird interessant, wenn sie auf eine andere trifft. Sammle Beobachtungen in [[Connections]], verbinde sie mit einem Beispiel und schreibe auf, **was sich dadurch verändert**.

Die Farben haben eine Aufgabe: **Gold hebt hervor**, *Violett setzt einen anderen Ton*, und [[Connections|rosa Links führen weiter]]. Mit #gedanken und #prism lassen sich Spuren wiederfinden.

> [!tip] Weniger Oberfläche, mehr Platz
> In Style Settings lassen sich Ribbon, Tabs und weitere Bereiche einzeln automatisch ausblenden. Auf dem Handy bleiben die Bedienelemente sichtbar.

## Kleine Experimente

| Perspektive | Frage | Nächster Schritt |
| --- | --- | --- |
| Beobachten | Was fällt mir auf? | Ein konkretes Beispiel sammeln |
| Verbinden | Was hängt damit zusammen? | Eine zweite Notiz verlinken |
| Prüfen | Was würde dagegen sprechen? | Eine Annahme überprüfen |

```js
const observations = ["sehen", "verbinden", "verstehen"];
const nextThought = observations.map(word => `${word} → weiterdenken`);
```

> [!question]- Eine Frage zum Aufklappen
> Welche Verbindung würde ich ohne meine bisherigen Kategorien entdecken?

> [!warning] Platz für Zweifel
> Eine Notiz darf vorläufig sein. Markiere eine Unsicherheit, bevor sie wie eine Gewissheit aussieht.

---

==Ein guter Gedanke darf klein anfangen.== Eine zweite Zeile macht ihn oft schon klarer.

#### Details

Inline-Code wie `theme.css`, eine Fußnote[^1] und ein externer Link zu [Obsidian](https://obsidian.md) ergänzen die Notiz.

[^1]: Diese Beispielnotiz dient zugleich der visuellen Kontrolle von Typografie, Tabellen, Aufgaben, Links und Callouts.
