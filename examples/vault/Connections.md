# Connections

Zurück zum [[Prism Observatory]].

## Die Verbindung erklären

**Beobachtung:** Zwei Notizen verwenden unterschiedliche Worte für eine ähnliche Erfahrung.

*Vermutung:* Beide beschreiben, wie sich Aufmerksamkeit verändert, sobald etwas einen Namen bekommt.

> [!example] Eine Brücke bauen
> Schreibe einen Satz, der beide Gedanken verbindet. Wenn der Satz unklar bleibt, ist das eine nützliche neue Frage.

- Welche Gemeinsamkeit ist konkret?
- Wo endet die Ähnlichkeit?
- Welches Gegenbeispiel hilft beim Verstehen?
