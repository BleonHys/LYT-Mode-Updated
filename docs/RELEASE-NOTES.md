Focus-LYT brings LYT Mode's colors and typography together with Border-inspired panes and optional focus controls. Includes light and dark palettes, offline DM Sans/DM Mono, and Style Settings customization.

Install the theme with the attached `manifest.json` and `theme.css`, or extract the `Focus-LYT` folder from the ZIP into your vault's `.obsidian/themes/` folder.

The ZIP also includes example notes and the separate optional **Focus-LYT Controls** companion. It adds the reveal arrow and lock button, requires Style Settings, and is installed manually under `.obsidian/plugins/`. It is not installed automatically with the theme. All auto-hide settings start off. Assign a pin shortcut yourself if desired.

Tested with real Obsidian 1.8.10 and 1.14.4 on Linux and emulated touch layouts. Native Windows/macOS window controls and physical iOS/Android devices remain unverified.

Independent project based on LYT Mode by Nick Milo, with design contributions from Cecilia May, and Border by Akifyss. MIT for the theme and companion; embedded fonts retain SIL OFL 1.1. Full notices are bundled in the CSS and ZIP.
