# Changelog

## 1.0.0

First public release of **Focus-LYT**.

- LYT Mode's color palette and typography with Border-inspired panes, a new light palette and embedded offline fonts.
- Style Settings customization for colors, layout, writing focus and six opt-in auto-hide controls.
- A shared pin setting and the optional Focus-LYT Controls companion with a visible reveal arrow and a lock in the note tab bar.
- Keyboard access, reduced-motion support and touch-aware behavior.
- Public installation guides, demo notes and real screenshots for dark, light and focus states.
- Reproducible builds, container tests and GitHub validation/release workflows.
- Complete MIT and font license notices bundled in the theme CSS and release archive.

The project was developed locally before this release. See the [credits and notices](THIRD-PARTY-NOTICES.md) for the LYT Mode and Border foundations.
