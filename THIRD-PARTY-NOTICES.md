## Embedded fonts — SIL Open Font License 1.1

Eight WOFF2 payloads were extracted byte-for-byte from the supplied LYT `theme.css`. Only DM Sans and DM Mono are bundled. CSS weight descriptors follow the actual font metadata: DM Sans 400/700, DM Mono 300/500, each upright and italic. No glyphs or font binaries were modified. Fonts load from embedded data URLs; no font network request is required.
