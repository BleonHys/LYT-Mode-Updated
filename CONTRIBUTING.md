# Contributing

Bug reports, focused improvements and testing on additional platforms are welcome.

Before reporting a problem, check it with the current theme and disable unrelated CSS snippets. Include your Obsidian/theme/OS versions, color mode, relevant settings and steps to reproduce it. Use a sample note for screenshots.

The theme is maintained directly in `theme.css`. The optional companion lives in `focus-lyt-controls/`. Keep existing Style Settings IDs stable, and check changes in light and dark mode, Reading view and Live Preview. For focus controls, check both temporary reveal and pinning. The [example vault](examples/README.md) provides notes for trying these views.

Describe the visible change and how you checked it in your pull request. Preserve upstream copyright notices and font licenses. Contributions are distributed under the repository's [MIT license](LICENSE).
