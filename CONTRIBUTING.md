# Contributing

Bug reports, focused improvements and testing on additional platforms are welcome.

Before reporting a problem, check it with the current theme and disable unrelated CSS snippets. Include your app/theme/OS versions, color mode, relevant settings and steps to reproduce it. Use a sample note for screenshots.

For code changes, follow the [development guide](docs/DEVELOPMENT.md). Edit `src/*.css` rather than the generated `theme.css`, keep existing setting IDs stable, and include the rebuilt CSS. Run static checks, documentation checks and relevant container scenarios. Describe the visible behavior and validation in the pull request.

Preserve upstream copyright notices and font licenses. Contributions are distributed under the repository's [MIT license](LICENSE).
