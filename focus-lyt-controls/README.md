# Focus-LYT Controls 1.0.0

Diese optionale Begleiterweiterung ergänzt Focus-LYT um einen dezenten Pfeil mit einer 48 × 24 px großen Hover-Fläche und ein Schloss direkt in der Notiz-Tableiste. Der Pfeil verschwindet nach dem Öffnen, damit er keine Tabs verdeckt. Das Schloss bleibt beim Feststellen erreichbar.

`focus-lyt-controls` nach `<Vault>/.obsidian/plugins/` kopieren und **Focus-LYT Controls** unter Community-Plugins aktivieren. Das Theme Focus-LYT und das Plugin **Style Settings** werden benötigt. In Style Settings muss **Notiz-Tabs automatisch ausblenden** eingeschaltet sein.

Das Schloss und ein selbst zugewiesenes Tastenkürzel verwenden denselben Style-Settings-Befehl und dieselbe gespeicherte Einstellung. Unter **Einstellungen → Tastenkürzel** lässt sich für **Leisten anheften** beispielsweise **Strg+Alt+P** vergeben; es wird kein Tastenkürzel voreingestellt. Die Erweiterung speichert keinen zweiten Pin-Zustand. Ohne Style Settings erklärt eine Meldung die fehlende Voraussetzung.

Auf Mobilgeräten bleibt die Erweiterung ohne Bedienelemente und verändert die native Navigation nicht. Beim Themewechsel oder Deaktivieren entfernt sie ihre Elemente. Sie liest keine Notizdateien und verwendet keine Netzwerkverbindung.
